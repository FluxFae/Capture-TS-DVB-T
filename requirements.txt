# Compatible-release bounds (~=): patch/minor fixes are accepted, a new minor is not.
# These are the versions the suite and the real tuner were verified with.
#
# Known and intentional gap: uvicorn[standard] also declares python-dotenv, which is
# only used by `uvicorn --env-file` (this app never passes it). Nothing imports it and
# the app was verified to boot and record with it uninstalled, so it is absent from the
# development venv on purpose. A clean install will pull it in; that is expected and
# harmless. Do not declare it here: it is not an application dependency.
#
# Do not replace uvicorn[standard] with a hand-written list of its internals. It was
# considered and rejected: uvicorn raises those floors between releases (0.54 already
# requires httptools>=0.8.0), so a manual list goes stale silently while the extra
# updates itself.
fastapi~=0.136.1
uvicorn[standard]~=0.46.0
jinja2~=3.1.6
python-multipart~=0.0.28
websockets~=16.0.0
